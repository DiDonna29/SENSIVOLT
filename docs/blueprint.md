# **App Name**: Sensivolt

## Core Features:

- Input Fields for DPI & Sensitivity: Allow users to enter their current mouse Dots Per Inch (DPI) and in-game sensitivity values.
- Game Selection Dropdowns: Provide intuitive dropdowns for users to select the source and target tactical FPS games for conversion.
- Real-time Sensitivity Conversion: Implement the core mathematical logic to instantly convert mouse sensitivity between selected games based on inputs.
- Display Converted Sensitivity: Clearly show the calculated new sensitivity value for the target game in an easy-to-read format.
- Internationalization (i18n): Support multiple languages (English and Spanish) for all UI text and labels to cater to a global audience.
- Dark Mode Toggle: Enable users to switch between a light and a dark visual theme, as requested by the competitive gaming aesthetic.

## Style Guidelines:

- Light Mode Background: #FFF1F2. A subtle, light base that allows interactive elements to strongly stand out for a modern gaming aesthetic.
- Light Mode Primary Accent: #E11D48. This aggressive, vibrant rose color serves as the primary visual focus for interactive elements, highlights, and critical information, embodying the competitive gaming spirit.
- Light Mode Container Background: #FFFFFF. Pure white for data containers and input fields ensures clarity and high contrast.
- Light Mode Text Color: #4C1D95. A rich, deep purple-blue for body text provides strong readability and sophisticated contrast against light backgrounds.
- Dark Mode Background: #171717. A deep, almost black background sets a serious, focused tone typical of high-performance gaming interfaces.
- Dark Mode Primary Accent: #F43F5E. A bold, energetic fuchsia-red serves as the primary highlight and interactive color, injecting vibrancy and aggression into the dark theme.
- Dark Mode Container Background: #262626. A slightly lighter dark grey for distinct UI sections, maintaining visual hierarchy without being jarring.
- Dark Mode Text Color: #D4D4D8. A soft, almost white grey ensures optimal readability for all text content against the dark background.
- Headlines and Body Text: 'Space Grotesk' (sans-serif). Chosen for its techy, modern, and clean appearance, it resonates with the competitive gaming utility while ensuring readability for input fields and results.
- Utilize sleek, minimalist, and sharp geometric icons that complement the high-performance and tactical nature of FPS gaming. Avoid overly elaborate or cartoonish designs.
- A highly functional and clean layout focusing on efficiency. A two-column or side-by-side design for source and target game inputs will ensure an intuitive comparison. Emphasize responsive design for various screen sizes.
- Subtle, fast, and responsive animations for state changes such as dropdown expansions, input focus, and result display to enhance user experience without causing distraction during conversions.
